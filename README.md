# Quick Light ⚡
A fast, beautiful spotlight-style application search launcher for GNOME Shell.

## Overview
Quick Light brings macOS Spotlight / Raycast-style instant search overlay to GNOME Shell desktop environment.

## Features (In development)
- Centered spotlight search window overlay
- Seamless integration with GNOME Shell overview search providers
- Global configurable shortcut triggering
- Multi-monitor support with cursor follow
- Modern glassmorphism dark aesthetic
